# Product and monetization planning

CHG-032 current public availability is governed by [build editions](../requirements/build-editions.md): two-gun public creation under CHG-034, no new custom creation or advanced graphs publicly; full preview retains them. Existing data/preset editing/use/export/restore remain available. This overrides earlier all-free availability statements for these actions without implementing billing or deleting data. Publication/deployment are tracked separately.

- [Monetization rollout plan](monetization-rollout.md): staged research, feature allocation, recovery, entitlement, pilot and launch gates. Planning only; implementation requires later approval.
- [Competitor research](competitor-analysis.md): dated first-party findings, source/access limits, candidate comparison and pending localized pricing verification.
- [Cloud architecture proposal](../architecture/cloud-services-proposal.md): auth/storage alternatives, owned backups, recovery, deletion and later synchronization.
- [Web commercial roadmap](../project/web-commercial-plan.md): current ordered work and completion gates.
- [iPhone/Android release guide](../development/NATIVE_RELEASE.md): retained for later; native releases are deferred by CHG-026.
- [Implementation history and remaining plan](../project/implementation-history.md): what is implemented versus proposed.

Billing/accounts/cloud and the final paid offer remain plans. CHG-032 specifically implements temporary public creation/graph restrictions with retained full preview and existing-data access; deployment is tracked separately. No customer payments or subscriptions are introduced.
